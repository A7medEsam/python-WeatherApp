# python-WeatherApp

App description :  you can find the weather of any city through typing the city's name

 The weather data is requested from openweathermap.org/api API

## Libraries Used : 

1. sys ( for application handling )
2. PyQt5 ( for GUI )
3. requests ( For API requests )

## how to run the application : 

if the certain library is not installed, install it through running the command : pip install [library name]
